# Tracked Topics

Topics you're actively following. The `/today` skill searches Slack for updates on each active topic.

## How to manage

- **Add a topic**: Add a new entry below with `status: active`
- **Pause**: Change `status` to `paused` (skipped but kept for later)
- **Remove**: Delete the entry or set `status: archived`
- **Expiry**: Set `expires` to auto-stop tracking after a date
